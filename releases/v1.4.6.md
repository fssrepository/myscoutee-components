# v1.4.6 — MSC-127 shared UI and package consumption

`@fssrepository/myscoutee-components@1.4.6` is distributed through GitHub Packages
(`https://npm.pkg.github.com`). The source tag is `v1.4.6`. Applications install
this exact version and commit the registry-backed lockfile; they no longer need
a nested source checkout, npm workspace or library watch process.

1. Consolidate menu presentation and placement, popup controls, card menus,
   rating-card interactions and frame bindings, route-map actions, FormFlow path
   parsing, page labels and indicator gradients. Existing rating articles and
   fullscreen wrappers remain; no extra DOM element or lazy boundary is added.
2. Preserve the single/pair badge defaults, desktop/mobile aspect ratios,
   remembered image selections, menu callbacks, pair split behavior and distinct
   card-menu palettes/surfaces. Native labels now reference their controls;
   index-aware visible-item predicates receive both arguments. Calendar counters
   now honor the previously declared font size/weight after `font: inherit`.
3. Publish foundation/core/cards/date/forms entry points alongside the compatible
   root entry. Keep the existing dynamic import boundaries and lean menu trigger.
   Applications continue to own transport, translations, data and business rules.
4. Qualification: 93 targeted component tests pass, including article DOM
   structure and fullscreen/list transitions; ng-packagr builds every entry point.
   A focused V8 run produces LCOV. Sonar imports it and reports **0 duplicated
   lines, 0 open findings, 28.4% combined coverage (30.5% lines)**. Coverage is from
   the selected 13 test files, not the complete suite. The coverage quality-gate
   condition remains below its configured threshold; no exclusion masks it.
5. The original 29 findings include 25 code repairs and four individually
   reviewed dispositions: preserve the public popup `close` output, retain signed
   32-bit image hashing, accept a nonsecurity UI history marker and recognize a
   Sass mixin selector as scoped after expansion. No rule is disabled globally.

Build with `npm run build`, then prepare the completed output with
`npm run prepare:release`. Publish the reviewed archive from `dist`, never the
private source workspace. Run the shared Sonar tool against this repository's
`config/sonarqube`, using the existing MyScoutee instance on port 9000.
