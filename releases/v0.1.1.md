# v0.1.1 — Built-in route control loading

Fix FormFlow's dynamic loader so it resolves built-in controls as well as consumer
registrations. Previously the route field was omitted when the application
registered pricing and policies without a route override. Consumer overrides keep
precedence.

Includes a regression test rendering RouteInput through FormFlow and editing its
stops. Built with the existing frontend-sync pipeline; browser validation covers
route editing, persistence and reopening in the application.
