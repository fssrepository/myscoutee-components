# MyScoutee Components 0.1.0

Release date: 2026-10-10. Git tag: `v0.1.0`.

## Changes

- First independently buildable Angular component library extracted from MyScoutee.
- Configurable menus (including the existing on/off toggle presentation), popups,
  dialogs, forms, date/link/location/route/slot inputs, SmartList and calendar/card views.
- Image carousel/gallery, deployment branding, prompts, loading indicators and floating launchers.
- Shared calendar conversion, schedule normalization, overlay/media stores, guide engine,
  translation contracts, directives and Sass modules.
- Complete component catalogue and consumer setup in README.
- Consumers supply translation, branding, media and domain integrations through the public API.
  MyScoutee continues to consume the same repository as its `components` Git submodule on `master`.

## Verification

The tag workflow runs the independent component tests, builds with ng-packagr,
checks the archive contents and publishes that exact archive. It creates this
GitHub Release only after successful GitHub Packages publication.
The consuming MyScoutee dev stack is also built through its existing frontend-sync process.
This library release does not claim full application lifecycle or backend deployment qualification.

## Installation

Configure `@fssrepository:registry=https://npm.pkg.github.com` in the consumer's
`.npmrc`, authenticate to GitHub Packages, then install
`npm install @fssrepository/myscoutee-components@0.1.0`.

Existing source consumers update the submodule with a fast-forward merge on `master`.
The frontend submodule path is `components`; public imports use `@fssrepository/myscoutee-components`.
No MyScoutee API, Firebase configuration, backend image or database migration is bundled.
