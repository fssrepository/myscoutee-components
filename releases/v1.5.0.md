# MyScoutee Components 1.5.0 — MSC-128

The tour-highlight reissue keeps its base glow continuously visible and pulses
only an additional glow layer. Target geometry, pointer handling, the 1.8-second
rhythm and reduced-motion behavior stay intact. Three uninterrupted cycles in
an isolated Chromium fixture retain the base glow and animation timeline, with
no jump at the cycle boundary and no ongoing paint events. The eight focused
TourDialog component tests passed. This is a CSS fixture measurement, not an
application-wide CPU result.

The menu-style reissue shares palette CSS between full menus and detached
triggers, preserving the public API and selector specificity. Applications need
no additional Sass import. Menu Sass removes overwritten declarations and
combines identical mobile rules; detached triggers omit panel-only rules.
InfoCard and ImageCard image loaders stop rendering outside the loading state,
so invisible spinners no longer animate after image success or failure.
Focused menu validation passed all 31 tests, including palette lifetime and scope.

computed-style differences across 152 desktop/mobile and normal/hover/active/
disabled fixtures. The combined scoped menu/trigger CSS, including the shared
palette once, decreased from 144,112 to 119,440 bytes; gzip decreased from 19,360
to 15,466 bytes in the same compiler fixture.

in the packaged startup graph. This reissue retains version 1.5.0 at the user's
explicit request; consumers refresh their locked artifact integrity.
